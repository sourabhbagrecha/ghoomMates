# Frontend

React + TypeScript single-page app built with [Vite](https://vite.dev).

Use `src/` for application code, `public/` for static assets, and `tests/` for tests.

## Development

Requires Node.js 20.19+ or 22.12+. Run these from the `frontend/` directory:

```bash
npm install
npm run dev       # start the dev server at http://localhost:5173
npm run build     # type-check and build to dist/
npm run preview   # serve the production build locally
npm run lint      # lint with oxlint
```
